# Portal's docs

The user's guide, a page for each subject:

- [Sessions](sessions.md): opening a session, the search form, aliases and zoxide, keys in a session, and one terminal at a time
- [Resume hooks](resume.md): bringing commands back after a reboot, and the resume panel
- [How it works](how-it-works.md): zmx and its directory, the saver, and restoration after a reboot
- [Commands](commands.md): every command and flag
- [Configuration](configuration.md): the config files and their paths, `prefs.json`, the attach keys, logging and privacy
- [Themes](theming.md): the colour roles, the `.theme` format, and the light/dark pair
- [Custom terminals](custom-terminals.md): `terminals.json` recipes for opening windows on terminals other than Ghostty
- [Troubleshooting](troubleshooting.md): `doctor`, `doctor --fix`, and the logs

[The design](design/zmx-backend.md) is how Portal is built on zmx and why.
