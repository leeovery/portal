# Session Control Overlay

A Portal pop-up overlay accessible from inside tmux while an agent runs, surfacing the relevant Portal and tmux session-control actions cleanly: rename, detach and quit across panes, windows and sessions. Replaces the existing Alt+M tmux overlay tool the user relies on today. Explicitly not a full tmux reimplementation; only the actions worth surfacing through Portal. Raised in conversation and confirmed in scope; not covered by the imported control-plane plan.
