# Mobile Client

A structured-first mobile client, the inverse of a terminal-first app with status bolted on. Surfaces: a control tower live session list with agent state (Waiting first) as the home screen; approval cards to approve or deny a waiting tool call, wired to lock-screen notification actions; a native compose box that sends to the pane via tmux send-keys (autocorrect, dictation, multi-line, image paste, local until sent); an embedded real terminal for the raw view (GhosttyKit / libghostty is the lead), kept hot across sessions with Mosh for resilience and predictive echo; a native diff viewer over git diff in the session git root; and an in-app browser preview over a forwarded dev-server port. Open and routed to research: client framework (the Moshi RN/Expo stack is a strong lead but undecided) and terminal engine (GhosttyKit lead, not finalised).
