# Transport

Connectivity between phone and host, deliberately split into two planes. Data plane: Tailscale by default (free), the daemon API on the Tailscale interface of the host, reached peer-to-peer over WireGuard, with the embedded terminal over Mosh/SSH. Relay (Pro): a hosted rendezvous relay for simpler setup where the daemon holds an outbound connection and the phone meets it in the middle, kept private by end-to-end encryption with the relay as a dumb forwarder; never the only path because of the trust cost, and the natural basis for a later team story. A minimal push/APNs path so a block reaches the phone. A thin launchd boot agent so the reboot-then-pick-up-on-phone case works without first sitting at the desktop. An optional future custom multiplexed protocol (efficiency and battery, not the moat). Routed to research: relay implementation, end-to-end encryption specifics and the APNs path were discussed at a high level only.
