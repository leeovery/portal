  FIX: restore `ast.Inspect(source.File, …)` over the whole file and resolve the enclosing function by position instead of by iteration — pre-collect the file's `*ast.FuncDecl`s and pick the one whose `Pos()..End()` contains the call, passing `nil` when none does.
