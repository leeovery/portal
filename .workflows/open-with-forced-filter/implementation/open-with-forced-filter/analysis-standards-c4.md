  FAILURE: A reviewer at a visual gate runs the documented live-view command (`go run ./cmd/capturetool --fixture sessions-search-results`) and sees `/home/user/code/portal` beside every row instead of `~/code/portal`. The directory column's home-abbreviation rule — the one this feature introduces and the one the frame exists to show — is invisible in the frame being signed off, and the widths the truncation ladder is judged at are wrong by the length of the home prefix. Pinning `HOME` on that command is not an escape: `HOME=/home/user go run ./cmd/capturetool …` fails outright with `failed to initialize build cache at /home/user/Library/Caches/go-build`, which is why the tape has to build a binary first and pin `HOME` only on the run.
  FILES: internal/capture/fixtures.go:462-470, internal/tui/session_dir_column.go:28, internal/resolver/path.go:94, testdata/vhs/sessions-search-results.tape:30, internal/capture/swap_harness_test.go:67
  DESCRIPTION: `fitSessionDir` renders through `resolver.AbbreviateHome`, which folds a path only when it sits under the *process's* `$HOME`. The fixture hardcodes its session directories under a literal `/home/user`, so the abbreviation fires only for a process whose home is that directory. The consequence has already had to be worked around three separate times rather than fixed: the tape splits build from run so it can prefix `HOME=/home/user`, `internal/capture/capture_test.go` pins `HOME` before every frame read, and the swap-and-diff completeness guard's own entry says it cannot judge the abbreviated forms at all ("Rendered under the developer's own home…") and asserts only `/opt/portal-tools`, the one path that is absolute by design. The fixture's own doc comment claims the frame carries "a home path shown abbreviated", which holds under the pin and not under the documented command. CLAUDE.md states the harness "renders a named deterministic fixture", and `capturetool --fixture` is named there as the only route to seeing a visual change before release — a fixture whose rendered text depends on an ambient environment variable breaks both.
  RECOMMENDATION: Build the fixture's home-relative directories from `os.UserHomeDir()` (degrading to the current literal when it errors) rather than hardcoding `/home/user`, applying the same derivation to the matching `project.Project` paths so the index still pairs with them. `AbbreviateHome` then folds them to `~/code/portal` under any `$HOME`; `/opt/portal-tools` stays absolute by construction. The `HOME` pin can then come out of the tapes, out of `capture_test.go`, and the swap-and-diff entry can assert the abbreviated form it currently has to sit out.
