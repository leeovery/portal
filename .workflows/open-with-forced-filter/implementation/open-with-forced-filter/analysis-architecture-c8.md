  DESCRIPTION: The sigil rule is now declared in two layers that answer differently. `cmd` answers it completely: `openCmd.RunE` short-circuits a sigil into `runSearchForm` before resolution, and `validateSearchFormCollisions` refuses every line where a sigil sits beside anything else — so no sigil can reach `Resolve` through the `open` surface, including the burst's `ResolveBareAll`. `internal/resolver` answers it partially: `IsPathArgument` was narrowed to return false for the shape, which removes only the *path* leg of the chain. The partial declaration is the problem, not the guard above it: a layer that takes on a rule should hold the whole of it, or none of it. As written the resolver holds a fragment whose only effect, if ever exercised, is to route a session-domain argument into a minting domain.
