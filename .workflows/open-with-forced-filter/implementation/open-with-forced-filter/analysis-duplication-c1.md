- FINDING: The set of sessions the picker lists is derived independently on the count path and on the render path
  SEVERITY: medium
  FAILURE: A later change to which sessions the picker shows — hiding a gone-flagged row, listing the current session with a marker, filtering on any new predicate — lands in one copy. `x /term` then takes K over a different set than the list it hands the user: it attaches a session the picker would never have offered, or paints a one-row picker after promising to attach when exactly one matched. Nothing fails to compile, `cmd`'s exclusion tests and `internal/tui`'s list tests both stay green, and the user notices only as "portal attached me to a session I did not pick".
  FILES: cmd/open_search.go:99-112, internal/tui/model.go:1115-1126, cmd/open.go:722-728
  DESCRIPTION: The specification makes the identity of the two sets a requirement — the searched set is the set the picker lists — and the code encodes that set twice. `searchCandidates` reads `tmux.InsideTmux()`, then `CurrentSessionName()`, treats a failed or empty read as "exclude nothing", and deletes the current session from the enumeration. `Model.filteredSessions` re-states the same rule over `m.insideTmux` / `m.currentSession`, whose values come from a third copy of the same guard in `openTUI` (`if tmux.InsideTmux() { name, err := CurrentSessionName(); if err == nil && name != "" { … } }`). On the deferred cold-boot route both copies run in the same invocation — `openTUI` reads the current session to build the model, and the decide closure reads it again at the loading gate — so the same value is fetched twice by two rules that nothing couples.

  DESCRIPTION: The matched field set — session name plus recorded directory in home-abbreviated form — is a rule the three filter entry points share by design; only the matching rule diverges between them. `resolver.MatchesSearchTerm` states that set as two `strings.Contains` arms over `name` and `AbbreviateHome(recordedDir)`, with an empty directory falling back to the name alone. `SessionItem.FilterValue` states the same set again as `Name + " " + AbbreviateHome(Dir)`, with the same empty-directory fallback and the same abbreviation.
