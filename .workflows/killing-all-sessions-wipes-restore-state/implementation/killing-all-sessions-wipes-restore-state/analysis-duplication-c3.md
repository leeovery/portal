SUMMARY: The rules this work unit adds each live in one place. The own-server confirmation lives in confirmOwnServer, and its three uses (after the capture, after a failed capture, and before an empty scrollback write) all route through it. Other single-source rules: the failure wording (cycleFailureMessage), the own-server pid (ownTmuxServer over tmux.ServerPIDFromEnv), the session-name listing (sessionNames under both ListSessionNames variants), the shell pending-marker gate (paneStillPending, used by both the backstop and the draw loop), the SIGTERM catch (catchSIGTERM, used by both draw and wait) and the hook shell argv (hookExecArgs). The near-duplicates that remain cannot drift silently. One is the shared eligibility test in keepAnsweredTranscripts and heldTranscripts; the commit_cycle_answered suites cover both the dump-writes path and the no-dump path, so a drift would fail them. The other is the five ErrTmuxStoppedAnswering wrap sites; dropping a wrap still ends the cycle uncommitted, so no data is lost, and only the "backed off" line changes, which the back-off suite asserts.
