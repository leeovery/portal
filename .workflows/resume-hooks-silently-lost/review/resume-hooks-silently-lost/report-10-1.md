FINDINGS:

  judged package's directory", and `sourceDir`'s doc at line 52 says it is "the directory the judged package's own

  The tree has such a caller today: `cmd/capturetool/import_guard_test.go:33` anchors at

  `github.com/leeovery/portal/cmd/capturetool`, so the directory opened is the module root and `cmd/capturetool`'s

  the judged package's own only when the caller named none — in both comments; `PackageDeps`' own doc at line 145
  already hedges it correctly and needs no change. FAILS: a contributor adding a guard in the shape capturetool
  already has (judge package X from a test in package Y, anchored with `InDir`) reads these comments as a promise

  cached pass this task exists to remove. Remedy is comment text only, so it is not blocking.
